# E-Learning Portal

## Project Description

A web-based E-Learning Portal developed using PHP and MySQL.

The system provides separate modules for Admin and Students.

## Technologies Used

- HTML
- CSS
- Bootstrap
- PHP
- MySQL
- JavaScript
- Chart.js


## Features

### Student Module

- Student Registration
- Login
- View Courses
- Enroll Courses
- My Courses
- Profile Management
- Change Password
- Course Completion Tracking


### Admin Module

- Admin Dashboard
- Manage Courses
- Manage Students
- View Enrollments
- Reports
- Export CSV
- Statistics Dashboard


## Database

Database Name:

elearning_portal


## How to Run

1. Install XAMPP
2. Start Apache and MySQL
3. Copy project into:

xampp/htdocs/

4. Import database in phpMyAdmin
5. Open:

localhost/elearning_portal
